# 影·筛 使用说明（macOS）

## 一、这是什么

影·筛 是一个专门用来“快速挑照片”的小工具。

你打开一个装满照片的文件夹，觉得哪张好，就双击那张的缩略图（或者按 X / 回车）。
它会立刻把这张照片复制到当前文件夹下的「筛选」文件夹里，同时给缩略图打一个绿色对勾。

- 原目录里的照片**永远不会被删除**
- 双击已经打过勾的照片 = 取消，把「筛选」里的副本丢进废纸篓
- 想反悔？按 ⌘Z 撤销
- 连点 10 张也没问题，10 张会按点击顺序各自处理

## 二、安装

1. 双击 `影·筛-1.0.2-macOS-arm64.dmg`，把「影·筛」拖到「应用程序」。
2. 第一次打开如果系统提示“无法验证开发者”：
   打开「终端」，粘贴这一行并回车：
   ```
   xattr -cr "/Applications/影·筛.app"
   ```
   然后再双击应用即可。也可以右键应用 → 打开 → 仍要打开。
3. 第一次选择桌面 / 文档里的照片时，macOS 可能问“想访问…文件夹中的文件”，点「允许」。
   这是 macOS 的隐私保护，不是软件在联网。

## 三、三步上手

1. 点左上角「打开文件夹」，选一个照片文件夹；或者直接把文件夹拖进窗口；
   也可以在访达里右键某张照片 → 打开方式 → 影·筛。
2. 点下方缩略图选照片，上方大图查看。滚轮缩放，按住拖动平移，双击大图恢复适应窗口。
3. 看到满意的：双击缩略图，或按 X / 回车。它会被复制到「筛选」子文件夹。

## 五、复制还是移动？

顶部有「复制 / 移动」开关，设置里也能改。

- **复制（推荐）**：原文件留在原目录，「筛选」里多一份副本。取消时删除副本（进废纸篓）。
- **移动**：把原文件直接移进「筛选」。取消时再移回原位（同名冲突会自动改名，不覆盖）。

每条标记记录会记住自己是用哪种方式产生的。中途切换开关，只影响之后的新操作，
之前用复制产生的项在取消时仍然是“删副本”，不会被误移回。

## 六、数据都在哪

- 状态索引：`~/Library/Application Support/影·筛/state/`
- 缩略图缓存：`~/Library/Application Support/影·筛/cache/`
- 设置：macOS 系统偏好（`com.jadis038.photocull`）

应用不联网、不上传任何照片。缓存上限默认 5GB，按最久未用自动清理，可在设置里清空。

## 七、更新

每次启动会自动检查 GitHub 上有没有新的 macOS 版本（可在设置里关闭）。
如果有，会弹出窗口让你决定是否更新；点「下载并安装」后会下载、替换应用并自动重启。
应用需要放在「应用程序」文件夹里才能自动替换。

## 八、常见问题

**1. 为什么有的 X3F 打不开？**
Sigma / Polaroid 的 X3F 是 Foveon 专有格式，macOS 系统图像框架没有解码器，本软件也不内置第三方 RAW 库，所以无法预览。其他常见 RAW（NEF/CR2/CR3/ARW/RAF/ORF/RW2/PEF/DNG/SRW…）都支持。

**2. 为什么缩略图有点糊？**
为了速度，RAW 缩略图直接使用相机内嵌的小预览图（单张约 0.5 毫秒）。上方大图会加载 2048px 预览，按 ⌘1 会后台加载完整原图，画质是完整的。

**3. 按了红色叉叉，应用直接退出了？**
这是特意设计的：影·筛 点红色关闭按钮就是退出应用，不需要再按 ⌘Q。

**4. 双击没反应？**
请确认点的是下方缩略图，不是大图。大图双击是“恢复适应窗口”。

**5. 在访达里删了「筛选」里的副本，软件还显示打勾吗？**
重新打开文件夹（⌘R 或重启应用）会自动校验：副本不在了，勾选会自动取消，不会丢状态。

**6. 想换图标 / 换名字？**
代码在源码包中，图标是 `Resources/AppIcon.icns`，可自行替换后重新运行 `./build.sh`。

## 九、卸载

把「影·筛.app」从「应用程序」拖进废纸篓即可。
应用缓存和索引不会自动删除；需要彻底清理时，删除 `~/Library/Application Support/影·筛/` 文件夹。
