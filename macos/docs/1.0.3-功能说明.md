# 影·筛 macOS 1.0.3 功能说明

- 版本：1.0.3（build 5）
- 日期：2026-11-27
- 对齐：Windows v1.0.6–v1.0.8
- 发布方式：**本轮仅本地开发，不上传 GitHub**

## 新增功能

### 1. 帧针模式（默认开启）
- 工具栏「帧针模式」复选框，状态持久化。
- 缩略图条中央显示 2px 橙色帧针（#FFC24B）+ 顶部三角，**指针固定不动**。
- 两侧动态留白，第一张和最后一张也能滚到针下居中。
- **普通鼠标滚轮每滚一格切相邻一张**（向下下一张，向上一张）；触控板仍可连续滚动；大图、绿勾、信息栏、计数同步。
- 键盘/单击/打开定位属于程序化选图：把图带到帧针下并做 220ms 判定抑制，避免互相拉扯。

### 2. 新键位
| 键 | 行为 |
|---|---|
| 空格 / X / 双击缩略图 | 标记 / 取消（画面停留当前图） |
| Z | 适应窗口 |
| Enter | 100%（像素 1:1） |
| ↑ / ↓ | 以画面中心为锚点放大 / 缩小约 10% |
| F11 | 全屏 / 还原 |
| 0 / 小键盘 0 | 清除星级 |
| 1–5 / 小键盘 | 标星；同键再按清除 |
| S | 保护 / 解锁 |
| ← / → / Home / End | 切图 / 首尾 |
| ⌘Z 或 Ctrl+Z / ⌘O 或 Ctrl+O / ⌘R 或 F5 | 撤销 / 打开 / 刷新 |

### 3. 保护锁定与星级
- 保护状态存 SQLite `locks`，星级存 `stars`，按源文件路径持久化，重启保留。
- 锁定后空格 / X / 双击 / 右键取消全部被拒绝，提示“该图已被保护锁定（按 S 解锁后再取消）”；撤销也不能取消受保护副本。
- 信息栏新增「保护」「星级」行；缩略图左上角显示 🔒 / ★n。

### 4. 原生缩放与无缝换原图
- 缩放百分比统一按**原图全分辨率**计算（不是预览图）。
- 预览图 → 原图只替换像素源，显示尺寸恒为 `原图尺寸 × 缩放`，中心、平移、百分比都不变；不会出现 770%/1000% 跳变。
- 触发全图：缩放 ≥95% 或预览显示倍率 ≥1.2；范围 2%–1200%。

### 5. 色彩空间直读
- RAW：EXIF/IFD0/Exif IFD/SubIFD 40961 → DNG AsShotProfileName（0xC6F6）。
- 1=sRGB、2=Adobe RGB、0xFFFF=未校准；没有就显示「—」，不采信系统推算的 ProfileName。
- Nikon NEF 通常没有该标签，显示「—」是正确行为。

### 6. 启动英文输入法
- 启动时通过 Carbon `TISSelectInputSource` 选择 ABC（或 US），失败静默。

### 7. 快捷键说明窗口
- 工具栏键盘按钮，或「帮助 → 快捷键说明」。
- 分节展示标记、视图、浏览、窗口全部键位与鼠标组合。

### 8. 其它
- 设置版本 1→2 迁移：旧配置没有帧针键或为关，升级后默认开启。
- 主窗口最小高度从 680 调整到 800，保证新增信息行不重叠。
- 旧功能保持：复制/移动、伴生文件、撤销、索引校验、单实例、红色关闭按钮退出、署名。
