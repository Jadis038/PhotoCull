# 影·筛 使用说明

## 一分钟上手

1. 打开「影·筛」（开始菜单，或在图片上右键 →「打开方式」→「影·筛」）。
2. 点左上角「打开文件夹…」，或者把文件夹直接拖进窗口。
3. 下方缩略图条里挑图：**单击缩略图**＝在上方查看这张图；**双击缩略图**（或按 `X` / `Enter`）＝
   把这张图复制进同目录下的 `筛选` 文件夹，缩略图右上角出现绿色对勾并变为灰调，画面停在这张图上，
   方便确认，按 `→` 或单击继续看下一张。
4. 标错了：对着已标记的图再按一次 `X`，`筛选` 里的那份副本会被删进回收站（可恢复），
   原目录里的原图不会动。
5. 全部看完，`筛选` 文件夹里就是你要留的图。

## 常见问题

**Q：标记会移动或删除原文件吗？**
不会。默认「复制」，原文件留在原地。设置里可切换为「移动」（移动模式下取消标记会把副本移回原位）。

**Q：`筛选` 文件夹什么时候创建？**
第一次标记时才创建，打开文件夹不会创建。

**Q：同名文件会覆盖吗？**
不会。`筛选` 里已有同名文件时会自动改名为「原名 (1).ext」、「原名 (2).ext」……

**Q：RAW+JPG 双拍怎么办？**
标记 NEF 时，同名 JPG 和 `.xmp`/`.aae`/`.thm` 会一起复制进 `筛选`。

**Q：我能在资源管理器里手动改 `筛选` 里的文件吗？**
可以。下次刷新/重启时程序会核对：副本被删掉的图自动取消勾选；副本被改名会按文件名重新匹配。

**Q：缩略图存在哪？**
`%LOCALAPPDATA%\影·筛\cache\`，上限默认 5GB，超出按最久未用清理。删除该目录只会让缩略图重新生成。

**Q：图片特别多，很慢？**
首次打开会在后台生成缩略图（2000 张约 1~10 秒，取决于硬盘）。之后切图都是缓存命中。
右下角状态区可以看到进度，也可以随时关掉程序，下次接着生成。

**Q：X3F 文件打不开？**
LibRaw 不支持 Sigma/Polaroid 的 X3F，会显示「无法解码」，不影响其它文件。

## 快捷键

| 键 | 作用 |
|---|---|
| `←` / `→` | 上一张 / 下一张 |
| 单击缩略图 | 在上方查看这张图 |
| `X` / `Enter` | 标记 / 取消标记（画面停留在这张图上） |
| `Ctrl+Z` | 撤销上一步 |
| `Ctrl+O` | 打开文件夹 |
| `F5` | 刷新 |
| 滚轮 | 大图上下平移（Photoshop 习惯） |
| `Ctrl` + 滚轮 | 大图左右平移 |
| `Alt` + 滚轮 | 以光标为中心缩放 |
| 双击大图 | 100% 像素 1:1（再双击回到适应窗口） |
| `0` | 适应窗口 |
| `1` | 100% |
| 左键拖动 | 平移大图 |
| 双击缩略图 | 标记 / 取消标记 |

## 数据位置

```
%LOCALAPPDATA%\影·筛\cache\   缩略图缓存（可安全删除）
%LOCALAPPDATA%\影·筛\state\   索引数据库（删了会按「筛选」内容重建）
%LOCALAPPDATA%\影·筛\settings.json  设置
```
