## 结论

- **34 个样本，32 个可打开**；只有 2 个 X3F 打不开（见下）。
- 32 个可打开的样本里，**22 个有内嵌预览**（JPEG 或未压缩 RGB 位图），缩略图是 0~21ms 级别的快路径；
  10 个 DNG 没有内嵌预览（多为手机 DNG），走「解一次 demosaic 兜底」慢路径，360~500ms，这类文件才会让首屏变慢。
- 全解耗时（100% 查看才用）：小型老机器 200~500ms，2000 万~4500 万像素 550~2100ms，均 < 3s 目标。
- 信息栏字段：多数 RAW 9/10（色彩空间常常取不到，显示「—」）；老机器/手机 RAW 6~8/10；
  Leaf Aptus 22.MOS 只有 3/10（该格式几乎没有 EXIF 镜头信息）。

| **X3F** | ✅ Polaroid x530 / Sigma dp2 Quattro | **不支持**：LibRaw 0.21.1 报「Unsupported file format」，WIC 也不支持。程序会显示缩略图占位 + 「无法解码」，不崩溃、不影响其它文件。 |
| JPG/PNG/TIFF/WebP | ❌ 样本里没有 | 代码走 WIC 路径，自检里用生成的 JPEG 覆盖了；建议补几张真实 JPG/PNG/TIFF/WebP 样本再验一遍 |

| RAW+JPG 双拍 | ❌ 样本里没有同名 JPG | 用「从 NEF 抽出的内嵌 JPEG」造了 IMG_0001.JPG 同主名样本，验证了双拍 + .xmp 一起进「筛选」 |
