        影·筛（PhotoCull）使用说明
════════════════════════════════════════════════════════

一、这个软件是干什么的？
────────────────────────────────────────
简单说：帮你快速"挑照片"。

拍了一两千张照片（RAW 或 JPG），不想一张张慢慢翻？
用影·筛：打开文件夹，看一张、留一张，双击一下，
被你留下的照片会自动复制到同一个文件夹下的「筛选」
子文件夹里。全部看完，「筛选」里就是你要的图。

放心：原照片永远不动、不删、不改。
不要了？再按一次 X，删掉的只是「筛选」里的那份副本，
而且会进回收站，还能找回来。


二、怎么安装？
────────────────────────────────────────
1. 双击 PhotoCull-Setup-x.x.x.msi（从 GitHub Releases 下载）
2. 一路下一步即可，不需要管理员权限
3. 装完在开始菜单里找「影·筛」

小提示：第一次运行如果 Windows 弹出蓝色提示
"Windows 已保护你的电脑"，点【更多信息】→【仍要运行】，
这是没有购买签名证书的正常现象，不是病毒。

软件会自己更新：每次启动时自动检查新版本，
有新版本会弹窗问你，同意后自动下载安装。


三、三步上手
────────────────────────────────────────
第 1 步：点左上角【打开文件夹】，
        或者直接把照片文件夹拖进窗口。
第 2 步：在下面的缩略图条里看图——
        ● 单击某张缩略图：上面大图显示这张
        ● 觉得好 → 双击这张缩略图（或按 X / 空格键）
          → 左上角出现绿色对勾，照片已复制进「筛选」
第 3 步：按 → 看下一张，重复第 2 步。
        全部看完，去文件夹里的「筛选」目录取图即可。

看错了？再按一次 X（或空格），副本进回收站，勾选消失。


三步上手（另一种玩法：帧针模式）
────────────────────────────────────────
勾选工具栏上的【帧针模式】，缩略图条中间会出现一条
黄色"针"（剪辑软件那种）：

  ● 左右滚动缩略图条，针指着哪张，上面就显示哪张
  ● 看中哪张，按空格键（或双击它）→ 复制进「筛选」
  ● 适合像刷视频一样"哗哗"快速过片

两种模式随时在工具栏切换，互不影响。


四、常用操作（快捷键）
────────────────────────────────────────
  单击缩略图 ............ 在上方查看这张图
  双击缩略图 ............ 标记 / 取消标记
  X 或 Enter ............ 标记 / 取消标记（同上）
  空格 .................. 标记 / 取消标记（同上，最快）
  ← → .................. 上一张 / 下一张
  Ctrl+Z ............... 撤销上一步
  Ctrl+O ............... 打开文件夹
  F5 ................... 刷新

大图相关（Photoshop 同款手感）：
  双击大图 ............. 放大到 100%（真实像素）
                        再双击 = 回到适应窗口
  ↑ .................... 放大约 10%
  ↓ .................... 缩小约 10%
  滚轮 ................. 上下移动
  Ctrl+滚轮 ............ 左右移动
  Alt+滚轮 ............. 放大 / 缩小（以鼠标为中心）
  按住左键拖动 ......... 移动画面
  0 键 ................. 大图适应窗口
  Enter ................ 全屏（不覆盖任务栏）/ 还原


三、五、保护与标星
────────────────────────────────────────
  按 S ................. 保护（锁定）当前照片
                        受保护的照片不会被取消筛选，
                        按 X / 空格 也不会删它的副本，
                        再按 S 解锁。
  按 1 ~ 5 ............. 给当前照片标 1~5 星
                        （小键盘也可以，再按同键清除）
  星级和保护都会记住，
  下次打开文件夹还在。


五、常见问题
────────────────────────────────────────
Q1：标记会移动或删除我的原照片吗？
    不会。原照片永远留在原地，软件只往「筛选」
    文件夹里复制一份。删除功能是没有的。

Q2：「筛选」文件夹是哪来的？
    第一次标记时自动创建，就在你的照片文件夹里。

Q3：两张照片重名怎么办？
    自动改名保存，比如「IMG_1 (1).jpg」，
    绝不会覆盖你已有的文件。

Q4：RAW+JPG 一起拍的怎么办？
    标记 RAW 时，同名的 JPG、XMP 等小文件会一起
    复制进「筛选」，一个都不会漏。

Q5：我手快连点了十几张，会不会乱？
    不会。点了几张就是几张，一张一张排队复制，
    某一张失败不影响其它张。

Q6：我在资源管理器里把「筛选」里的文件删了/改名了？
    下次打开软件会自动核对：删了的自动取消勾选，
    改名的自动重新对上，不会让你重新挑一遍。

Q7：不小心把原图搞丢了吗？怎么找回取消的照片？
    原图从未被移动或删除。
    取消标记只是把「筛选」里的副本放进回收站，
    双击桌面回收站即可恢复。

Q8：某张照片显示"无法解码"？
    少数专有格式（如适马 X3F、三星专有压缩 DNG）
    目前不支持，其它常见 RAW（尼康/佳能/索尼/
    富士/奥林巴斯/松下/宾得/大疆/手机 DNG 等）
    都没问题。

Q9：杀毒软件或系统提示风险？
    本软件开源（GitHub: Jadis038/PhotoCull），
    代码全部公开可审计，不联网上传你的任何照片。


六、照片和数据放在哪？
────────────────────────────────────────
你的照片 ............... 原地不动，只多一个「筛选」文件夹
挑出来的图 ............. 照片文件夹\筛选\
缩略图缓存 ............. C:\Users\你\AppData\Local\影·筛\cache
                        （删了也没事，会自动重新生成）
软件设置 ............... C:\Users\你\AppData\Local\影·筛\


七、信息栏怎么都是"—"？
────────────────────────────────────────
机型、镜头、光圈这些信息来自照片里的元数据。
手机导出的 JPG/HEIC/PNG 常常不含这些信息，
显示"—"是正常的；相机直出的 RAW 信息基本齐全。


八、一句话总结
────────────────────────────────────────
打开文件夹 → 单击看图 → 双击留图 → 全看完 →
「筛选」文件夹里全是你要的。
